# 🧩 친구 퀴즈 배틀

학생들이 **직접 문제를 내고**, 교사가 PLAY를 누르면 **다른 친구가 만든 문제를 랜덤으로 풀며** 점수를 겨루는 수업용 실시간 퀴즈 사이트입니다.

| 화면 | 주소 |
| --- | --- |
| 학생 | `/` (QR 코드 또는 `/?code=입장코드`) |
| 교사 대시보드 | `/teacher` |

## 수업 흐름

1. **교사**: `/teacher` → **새 방 만들기** → 화면에 4자리 입장 코드와 QR 코드가 나옵니다.
2. **학생**: 입장 코드 + 이름으로 들어와서 문제를 냅니다. (기본 1인 3문제, 설정에서 1~10개)
   - ✍️ **단답형**: 정답 입력. 정답이 여러 개면 쉼표로 구분 (`서울, 서울특별시`). 띄어쓰기·대소문자·문장부호는 무시하고 채점.
   - 🔢 **객관식**: 보기 1~4번 입력 후 정답 번호 선택.
   - 📝 **문장형**: 모범 답안 + **채점 핵심 단어**(쉼표 구분). 학생 답에 핵심 단어가 모두 들어 있으면 정답.
3. **교사**: 문제 탭에서 부적절한 문제를 지우고 **▶ PLAY**.
4. **학생**: 자기 문제를 뺀 친구들의 문제가 랜덤으로, 한 문제씩 나옵니다. 각자 자기 속도로 풀어요.
5. **교사**: 순위 탭(⛶ 크게 보기로 TV에 띄우기)에서 실시간 순위 확인 → **🏁 게임 끝내기**로 최종 시상대.

일시정지 / 문제 더 만들기 / 이어서 하기 / 점수 초기화 / 학생 내보내기도 대시보드에서 할 수 있어요.

## 점수 규칙

| 항목 | 점수 |
| --- | --- |
| 정답 기본 | +100 |
| ⚡ 스피드 보너스 | 남은 시간 비율 × 최대 +100 (빨리 맞힐수록 큼) |
| 🔥 연속 정답 보너스 | 2연속부터 1회마다 +20 (최대 +100) |
| 오답 / 시간 초과 | 0점, 연속 기록 초기화 |

제한 시간은 교사가 10~60초 중 고르며, 문장형은 2배 시간이 주어집니다.
점수는 `lib/grading.js`의 `SCORE` 값에서 바꿀 수 있어요.

## 실행 방법

### 방법 A. 교사 컴퓨터에서 바로 실행 (같은 와이파이)

[Node.js](https://nodejs.org) 18 이상 설치 후:

```bash
cd quiz-battle
npm install
npm start
```

터미널에 나오는 `http://192.168.x.x:3000` 주소로 학생들이 접속합니다.
교사 화면(`http://localhost:3000/teacher`)의 QR 코드도 자동으로 이 주소를 가리켜요.
※ 학교 와이파이가 기기끼리 접속을 막아 두었다면 방법 B를 쓰세요.

### 방법 B. 인터넷에 무료로 올리기 (Render)

1. [render.com](https://render.com)에 GitHub 계정으로 로그인
2. **New → Blueprint** → 이 저장소 선택 (루트의 `render.yaml`을 자동으로 읽어요)
3. 배포가 끝나면 나오는 `https://….onrender.com/teacher` 로 접속

무료 요금제는 15분 동안 접속이 없으면 잠들어서, 수업 시작 전에 한 번 열어 두면(첫 접속 약 1분) 좋아요.
서버가 잠들거나 재배포되면 방 데이터가 지워지니, 한 수업 안에서 쓰는 용도로 생각해 주세요.

## 개발

```bash
npm test   # 교사 1명 + 학생 3명 시나리오 자동 점검
```

- `server.js` — Express + Socket.IO 서버 (방·학생·문제 상태, 문제 배분, 채점)
- `lib/grading.js` — 정답 판정과 점수 계산
- `public/index.html`, `public/student.js` — 학생 화면
- `public/teacher.html`, `public/teacher.js` — 교사 대시보드

정답은 학생 화면으로 보내지 않고 서버에서만 채점하며, 걸린 시간도 서버 시계로 잽니다.
방 데이터는 `data/rooms.json`에 저장되어 서버를 껐다 켜도 24시간 동안 유지됩니다.
