# 🪄 AI 캐릭터 변신 부스

학생이 학습지에 그린 **나만의 캐릭터**를 휴대폰으로 찍으면, AI가 **양모펠트 인형·2D/3D 애니메이션** 같은 모습으로 바꿔 주고,
**패들렛**에 올린 뒤 부스에서 **포토프린터로 뽑아 주는** 체험 부스용 웹앱입니다.

| 화면 | 주소 | 누가 |
| --- | --- | --- |
| 학생 | `/` (QR로 접속) | 학생 휴대폰 |
| 교사 | `/teacher` | 부스 노트북 (포토프린터 연결) |
| 전시 벽 | `/wall` | TV·빔프로젝터 (패들렛 대신 띄워도 됨) |

## 부스 흐름

1. **학습지**: 학생이 취미·특기 등을 생각하며 자기 캐릭터를 그린다.
2. **QR 접속**: 교사 화면의 `📱 QR 크게 보기`를 띄워 두면 학생이 자기 휴대폰으로 들어온다.
3. **학생 휴대폰**
   1. 이름(별명) · 캐릭터 이름 · 한 줄 소개 입력
   2. `📷 카메라로 찍기` → 학습지 그림 촬영
   3. 변신 스타일 고르기 → `🪄 AI로 변신시키기!` (10~30초)
   4. 결과를 원래 그림과 나란히 확인 → 마음에 안 들면 다른 스타일로 다시 (기본 1인 3회)
   5. `📤 패들렛에 보내기`
4. **패들렛**: 보드에 `🧶 캐릭터 이름` 제목 + AI 그림 + 만든 친구·스타일·소개 글이 올라간다.
5. **교사 화면 → 🖨️ 인쇄 대기** 탭에 보낸 순서대로 쌓인다 → `🖨️ 인쇄` 한 번이면 포토용지 크기로 인쇄 창이 뜬다.

## 변신 스타일 (9가지)

| | 스타일 | 느낌 |
| --- | --- | --- |
| 🧶 | 양모펠트 인형 | 보송보송한 털실 인형을 실제로 찍은 사진처럼 |
| ✏️ | 2D 애니메이션 | TV 만화 주인공 (선명한 선, 셀 채색) |
| 🎬 | 3D 애니메이션 | 극장판 3D 애니메이션 캐릭터 |
| 🏺 | 클레이 인형 | 찰흙 스톱모션 인형 (손자국까지) |
| 🧱 | 블록 장난감 | 조립 블록으로 만든 피규어 |
| 👾 | 픽셀 게임 | 16비트 레트로 게임 캐릭터 |
| 🎨 | 수채화 동화책 | 그림책 속 주인공 |
| ⭐ | 반짝 스티커 | 흰 테두리 다이컷 스티커 (인쇄해서 오려 붙이기 좋음) |
| ✂️ | 종이 공예 | 색종이를 겹겹이 오려 붙인 입체 작품 |

교사 화면에서 쓸 스타일만 골라 켤 수 있어요. 스타일을 더 넣거나 지시문을 고치려면 `lib/styles.js`를 수정하세요.
모든 스타일은 "아이가 그린 모양·색·옷·표정은 그대로 두고 재질과 화풍만 바꾸라"고 AI에게 지시합니다.

## 준비물

### 1. Gemini API 키 (그림 변신용, 필수)

1. [Google AI Studio](https://aistudio.google.com/apikey)에 구글 계정으로 로그인 → **API 키 만들기**
2. 이미지 생성 모델은 **결제(빌링) 등록**이 필요할 수 있어요. 행사 전에 꼭 한 번 실제로 변신시켜 보세요.
3. 비용은 대략 **그림 1장에 수십 원** 수준이에요 (2026년 기준 공개 가격 약 $0.04~0.07/장).
   학생 100명 × 평균 2회 = 200장이면 대략 1~2만 원 안쪽. 정확한 가격은 Google 요금 안내를 확인하세요.
4. 학생 그림 사진이 AI로 전송되므로, **유료(결제 등록) 등급**에서 쓰기를 권장합니다
   (무료 등급은 입력 내용이 서비스 개선에 쓰일 수 있다고 안내돼 있어요 — Google 약관 확인).

> 모델 이름은 자주 바뀌어서, 앱이 `gemini-3.1-flash-image-preview` → `gemini-3.1-flash-image` → `gemini-2.5-flash-image` 순서로 쓸 수 있는 것을 자동으로 찾아요.
> 특정 모델을 쓰고 싶으면 환경 변수 `GEMINI_MODEL`에 적으세요.

### 2. 패들렛 API 키 + 보드 ID (패들렛 자동 등록용)

- 패들렛 API는 **유료 요금제**(개인 유료 또는 학교용 Padlet for Schools 등) 계정에서만 키를 만들 수 있어요.
- 키: 패들렛 **설정 → 개발자(Developer)** 화면에서 **Generate** → 나온 키를 `PADLET_API_KEY`에 넣기
  ([공식 안내](https://docs.padlet.dev/reference/introduction))
- 보드 ID: 글을 올릴 패들렛(내가 관리자인 보드)의 ID (16~22자). 교사 화면 **부스 설정**에 넣고 `🔌 패들렛 연결 테스트`로 확인하세요.
  보드 주소를 통째로 붙여 넣어도 끝부분 ID를 자동으로 떼어 써요.
- 패들렛 API는 파일을 직접 올리지 못하고 **그림 주소(URL)** 만 받을 수 있어요.
  그래서 이 앱이 그림을 인터넷 주소로 열어 두고 그 주소를 패들렛에 넘깁니다 → **반드시 인터넷에 배포(Render 등)해서** 써야 패들렛에 그림이 보여요.

**유료 패들렛이 없다면?** 교사 화면에서 `패들렛에 자동으로 올리기`를 끄세요.
학생이 보낸 그림은 그대로 교사 화면(인쇄 대기)과 **전시 벽(`/wall`)** 에 모이고, TV에 전시 벽을 띄우면 패들렛처럼 실시간으로 그림이 붙어요.

### 3. 포토프린터

- 부스 노트북에 포토프린터(캐논 셀피 등) 드라이버를 설치해 두세요.
- 교사 화면 **인쇄 설정**에서 용지 크기 선택: `10×15cm(4×6)` / `엽서 100×148mm` / `카드 54×86mm` / `A4`
- 인쇄 창에서 **여백 없음(테두리 없음)**, 배율 **100%(실제 크기)** 를 고르면 용지에 꽉 차게 나와요.
- 인쇄하면 자동으로 "인쇄됨" 표시가 되고 인쇄 대기 목록에서 빠져요. 다시 뽑으려면 `보낸 작품 전체` 탭에서.

## 배포 (Render 무료)

1. [render.com](https://render.com)에 GitHub 계정으로 로그인
2. **New → Blueprint** → 이 저장소 선택 (루트의 `render.yaml`에 이 앱이 들어 있어요)
3. 아래 값을 입력하라고 나오면 채우기

| 환경 변수 | 내용 |
| --- | --- |
| `GEMINI_API_KEY` | Gemini API 키 (필수) |
| `TEACHER_PASSWORD` | 교사 화면 비밀번호 (꼭 설정) |
| `PADLET_API_KEY` | 패들렛 API 키 (패들렛 쓸 때) |
| `PADLET_BOARD_ID` | 패들렛 보드 ID (교사 화면에서 넣어도 됨) |

선택: `BOOTH_TITLE`(부스 이름), `MAX_TRIES`(1인당 변신 횟수, 기본 3), `GEMINI_MODEL`, `AI_CONCURRENCY`(동시에 AI에 보내는 수, 기본 3), `PUBLIC_URL`(주소를 직접 지정할 때)

4. 배포가 끝나면 `https://….onrender.com/teacher` 로 접속

⚠️ **무료 요금제 주의**
- 15분 동안 접속이 없으면 잠들어요. 행사 시작 전에 교사 화면을 한 번 열어 두세요(첫 접속 약 1분).
- 서버가 다시 켜지거나 재배포되면 **저장된 그림이 지워질 수 있어요.** 행사가 끝나면 교사 화면의 `📦 보낸 작품 모두 내려받기 (ZIP)`로 꼭 백업하세요.
- 패들렛에 올라간 그림도 이 서버 주소를 가리키므로, 패들렛에 오래 남기려면 행사 후 확인해 보고 필요하면 ZIP의 그림을 패들렛에 직접 올려 두세요.
  (오래 운영하려면 Render 유료 요금제 + 디스크를 붙이고 `DATA_DIR`을 디스크 경로로 지정)

## 연습해 보기 (AI 키 없이)

```bash
cd ai-character-booth
npm install
MOCK_AI=1 npm start
```

`MOCK_AI=1`이면 AI 대신 찍은 사진을 그대로 돌려줘서, 키 없이 학생 화면 → 보내기 → 인쇄까지 전체 흐름을 연습할 수 있어요.
터미널에 나오는 `http://192.168.x.x:3000` 주소로 같은 와이파이의 휴대폰에서 접속하세요.
(카메라 촬영 버튼은 `http://` 주소에서도 휴대폰 기본 카메라 앱이 열리는 방식이라 그대로 동작해요.)

## 개발

```bash
npm test   # 가짜 Gemini·패들렛 서버로 학생→AI→패들렛→교사→인쇄→ZIP 전체 점검
```

- `server.js` — Express 서버 (업로드, AI 변신, 패들렛 전송, 교사 API, ZIP)
- `lib/styles.js` — 변신 스타일과 AI 지시문
- `lib/gemini.js` — Gemini 이미지 API 호출 (모델 자동 전환, 동시 요청 제한)
- `lib/padlet.js` — 패들렛 API (보드 확인, 글 올리기)
- `public/index.html`, `student.js` — 학생 화면
- `public/teacher.html`, `teacher.js` — 교사 화면
- `public/print.html` — 포토용지 인쇄 레이아웃
- `public/wall.html` — 전시 벽

API 키는 서버에만 있고 학생 휴대폰으로는 절대 보내지 않습니다.
사진은 휴대폰에서 긴 변 1280px로 줄여서 올리므로 데이터가 적게 들어요.
